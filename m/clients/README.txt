Customer logos
==============
The seven customer logos are already in this folder as transparent PNGs and show in the
scrolling strip on the Home and About pages:

  5-and-6-restaurant.png  brent-mall.png  ace.png  foodies.png  foodco.png
  everyday-kitchen.png  sunrise.png

To swap a logo later: save a new PNG (transparent background, at least 400px on its longest
side) with the SAME file name over the old one. No code changes needed.

The /originals folder keeps the files you sent, untouched.
